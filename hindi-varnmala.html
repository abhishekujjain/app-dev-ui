Complete Hindi Alphabet Reference

The Hindi varnmala (हिंदी वर्णमाला) uses the Devanagari script. Below is the full set of letters covered on this page — tap any letter above to hear pronunciation and see an example word.

Hindi Swar — 13 Vowels (स्वर)

अ आ इ ई उ ऊ ऋ ए ऐ ओ औ अं अः

Swar are independent vowel sounds. Each has a Roman transliteration: a, aa, i, ee, u, oo, ri, e, ai, o, au, an, ah.

Hindi Vyanjan — 36 Consonants (व्यंजन)

क ख ग घ ङ च छ ज झ ञ ट ठ ड ढ ण त थ द ध न प फ ब भ म य र ल व श ष स ह क्ष त्र ज्ञ

Vyanjan combine with matras to form syllables. Consonants are grouped by place of articulation in traditional Hindi teaching.

Hindi Matras — Vowel Signs (मात्रा)

Matras attach to consonants to change their vowel sound. For example, क + आ matra = का, क + इ matra = कि. This page demonstrates all matras using the letter क.

Frequently Asked Questions

What is Hindi varnmala?

Hindi varnmala is the complete set of letters in the Hindi language, written in Devanagari script. It includes swar (vowels), vyanjan (consonants) and matras (vowel signs).

How many letters are in the Hindi alphabet?

There are 13 swar (vowels) and 36 vyanjan (consonants), plus matras that modify consonant pronunciation.

Is this Hindi alphabet tool free?

Yes — this interactive Hindi varnmala page is completely free. No sign-up or download required. Works in any modern browser with optional text-to-speech for pronunciation.

How do I help my child learn Hindi letters?

Start with swar (vowels), then vyanjan (consonants). Let your child tap each letter to hear it spoken aloud, then try the quiz game to reinforce recognition.
